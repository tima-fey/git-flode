git-flode

A visual editor for existing Home Assistant automation YAML files in a configuration repository.

The integration appears as git-flode in Home Assistant.

The configuration project

  • automations/: existing YAML automation lists, organized in nested folders. Save updates the selected automation in its original file.
  • objects/: manually exported HA integration, device, entity, and helper metadata for reference checks.
  • tests/: trusted Python project tests, run explicitly in the HA environment.

Explicit operations

Review and commit local changes to prod, push them separately, and merge fetched updates from main. History displays commit diffs without switching the live checkout. Configuration checking and Quick reload use separate controls; saving or merging never reloads HA automatically.

The panel edits existing automation files. Creating automations, script-file editing, AI assistance, and running automation actions are outside this workflow.
